Knowledge Base

Find quick answers to common questions.

How do I reset my API key?
Navigate to the API Keys tab in the sidebar. Locate your active key and click the "Revoke" button, then click "+ Generate New Key" at the top right of the page.
What should I do if a server instance goes offline?
First, check the System Logs for any critical errors before the crash. If the instance is unresponsive, you can trigger a hard reboot from the Cloud Instances panel.
How do I change my notification preferences?
Head over to the Settings page. Under the "Notifications & Alerts" section, you can toggle critical alerts and weekly email digests.
How are cloud instances billed?
Instances are billed on an hourly basis. You can track your usage in real-time under Billing & Plan.
Which regions are available for deployment?
We currently support US-East, US-West, EU-Central, and AP-South regions.
What are the default API rate limits?
Starter plans include up to 1,000 requests/min. Pro plans have higher limits customizable in settings.
