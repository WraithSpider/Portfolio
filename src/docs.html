GridNode Infrastructure & Automation Docs

Real-time cloud infrastructure monitoring, AI automation script management, and secure API key administration.

Quick Start

Terminal
$ npm install -g @gridnode/cli && gridnode init
✓ CLI v6.4.0 installed
✓ Project initialised — cluster linked to us-east-1
Cluster Config
"cluster": { "region": "us-east-1", "metrics": { "frequency": "1s" }, "alerts": { "cpu_max": 85, "ram_max": 90 } }
AI Runner Hook
from gridnode import AgentHook @AgentHook.on("deploy") def on_deploy(event): return event.node.scale( replicas=+2, autoscale=True)

Platform Features

  • Real-time telemetry streaming — Live CPU, RAM, GPU, and network metrics pushed at sub-second latency.
  • Automated container scaling — AI agents observe load patterns and scale clusters predictively.
  • Zero-trust API key generation — Granular, per-scope keys with automatic rotation and revocation.
  • End-to-end encrypted log streaming — Tamper-evident audit logs delivered over authenticated channels.

Core Modules

Real-time Telemetry

Cluster metrics, health checks, and low-latency streaming across every node.

AI Script Engine

Deploy and schedule automated Python and Node workers on your clusters.
